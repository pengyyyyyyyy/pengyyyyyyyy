## Featured project

### RepoTrail

沿着源码依据，理解陌生的 Python 仓库。

从仓库入口与模块地图出发，生成可逐步阅读的路线，对照真实代码，并查看静态调用关系与待核实部分。

- Python AST 符号索引与版本化源码快照
- 受限源码工具、结构检查与一次补查修订
- 本地阅读工作区、CLI、Markdown 与 CodeTour 导出
- Requests、Click、Flask 的固定源码核对题集

目前正在补充真实模型对照与独立人工语义评分。
